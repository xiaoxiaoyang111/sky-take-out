## 复现

1. `scripts/Test-RentalFreshDatabase.ps1`会创建随机命名隔离库，初始化结构，启用真实数据库/Redis跑Java8兼容package，然后验证prod管理员初始化；最终仅删除自己创建的库。执行账号需有创建/删除测试库权限。
2. `frontend/rental-web`中执行`npm ci && npm test && npm run build`。
3. 启动实际本机服务后执行`node scripts/Verify-Rental.mjs`；有已配置模型时才加`--model`。该步骤会写入独立临时数据并清理，不能拿它验证任意正式环境。
4. `node scripts/Benchmark-Rental.mjs`重做只读本机目录样本。
