## 代码规范

- 保持现有 Java/Maven 版本；不因转型顺手升级依赖。租赁新增类型集中在 rental 子包，统一 Result/PageResult。

- 并发锁按 API.md 协议排序，数据库约束是最终防线；不可用“先查一下”替代事务内占用校验。
- 前端不写假成功、不硬编码账号密码；token 不进入 URL；错误、加载、空结果和重复提交有明确交互。
- 仅使用有源码的前端工程，不继续编辑压缩 bundle 实现新业务。
- 测试使用独立数据并清理，禁止清空已有表；补正常、边界、失败和核心并发测试。
- Git 保留既有历史；除非用户明确授权，不提交、推送、变基或强制推送。禁止提交 .env、node_modules、dist、日志、真实凭证。
